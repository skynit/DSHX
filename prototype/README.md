# Android 产品原型 · P0

这是早期方案验证阶段制作的 Kotlin 原生可操作原型，帮助目标用户在开始正式功能开发前检查产品流程。包名为 `local.dshx.prototype`，与将来的正式应用分开安装；无联网权限、无无障碍服务、无密钥输入，不调用模型、不操作其他应用。

当前实际运行的部分：系统选择 UTF-8 `.txt` / `.md` / `.json` 文件并复制到私有目录、同名文件保留独立副本、从 Markdown 提取未完成事项并保留原文行号、对照整理前后文本、一次撤销、冲突另存恢复副本、系统另存为新文件、进程重启后重新打开已落盘副本。256 KiB / 120 字符文件名是本轮原型试验限制；不承诺是正式版限额。取消或拒绝导入不修改原文件。

手机任务、模型接收方与数据授权、30 秒审批期限、停止、结果不明与人工核实、Full 进入/退出与恢复均是明确标注的演练。演练任务只在应用进程内保存；文件副本落盘。它没有后台服务、正式 SQLite 动作账本或运行时，不能据此判定 G1–G6 通过。正式版依然保留上游 dsh 引擎和网页聊天；这里没有重写聊天界面。

原型没有真实审核插件。T3 显示“尚未准备”，不把本地规则整理冒充插件成功。手机任务使用明确虚构的目标页面，不计入三个真实应用或兼容清单。

先用工作台的“用周会样本开始”，确认本次范围，执行本地整理，核对原文行号，再使用系统“另存为”。输出应与 [expected.md](src/main/assets/expected.md) 一致。导出回执只是系统写入返回，仍需在另一个应用打开内容，完成结果证据。外部写入异常会提示结果不明且保留本地副本，不自动重复写入。

## 构建与本包验证

需要 JDK 17、Android SDK Platform 34 和 Build Tools；首次构建还需要从 Google/Maven Central 获取构建依赖。构建联网和安装依赖发生在开发机，不代表原型获得运行期联网用途。SDK 位置写入不提交的 `local.properties`，例如 `sdk.dir=/你的/Android/Sdk`。

```bash
./gradlew :prototype:assembleDebug
./gradlew :prototype:testDebugUnitTest :prototype:lintDebug
```

只构建、验证 `prototype` 包，不运行全仓或参考项目测试。`targetSdk 28` 来自既定手动安装路线；Lint 仅豁免 Google Play 的目标版本上架检查，其他错误正常阻止通过。严格的可用空间预检不回收其他应用缓存，因此保留 `UsableSpace` 建议；它不是空间不足测试已通过的证据。

产物：`build/outputs/apk/debug/prototype-debug.apk`。这是开发调试签名的 P0 原型包；没有正式发布密钥和运行时。测试报告在 `build/reports/tests/testDebugUnitTest/`，静态检查在 `build/reports/lint-results-debug.html`。渲染检查在 `build/visual-checks/`，由 Robolectric 的 Android 测试环境生成，不是真机或模拟器截图。

## 组件与调用流程

| 名称 | 谁创建、负责什么、与相近组件的区别 |
|---|---|
| `MainActivity` | Android 创建的原生页面入口；显示工作台、文件、任务演练、引导和恢复演练，绑定原生控件与事件；不是正式服务端核心或聊天引擎 |
| `PrototypeApp` | Android 为本应用进程创建一次的共享状态；持有单后台执行线程、所选副本、演练阶段和当前页面；页面重建继续绑定同一状态，进程死亡后不恢复演练动作 |
| `Workspace` | `PrototypeApp` 在后台创建的文件副本管理对象；接收文本、原子替换副本、提取事项、检查结果版本并撤销；不具备正式文件沙箱或数据发送授权能力 |
| `TaskFlow` | `PrototypeApp` 创建的走查演练状态；约束提交确认、停止与结果不明的展示顺序；不签发执行凭证、不调用系统动作，也不代替正式 SQLite 账本 |
| Robolectric | 测试依赖提供的桌面 Android 测试环境，由 Gradle 本包测试启动；执行页面/文件用例及生成渲染预览；不能证明真实设备权限、进程恢复或系统文件提供方行为 |

文件选择返回后，页面把系统提供的读取引用交给后台线程；初始化尚未完成时，保留这次请求并在前一项本地工作完成后处理，不静默丢弃。这里仅串行处理原型文件工作，与正式手机任务调度无关。`Workspace` 校验类型、UTF-8、大小和空间，创建独立编号目录保存原文和当前副本，出错清理未完成目录。页面只展示成功导入的副本，原文件不写入。整理时先保存本次处理前内容及预期结果哈希，再原子替换当前副本；撤销比对当前结果版本，相同则恢复，不同则另建恢复副本。恢复副本名保留前缀和原扩展名，过长时截短中间名称，不因新增前缀超过原型长度限制。导出前冻结本次结果文本，系统选择目标后只写这份冻结内容，避免页面切换后误写另一份文件。

任务演练由同一份 `TaskFlow` 状态驱动，离开页面后仍显示固定任务条和直接停止入口。审批期限使用开机以来的单调时间，切到后台不会重置；未派发时停止进入“已停止”，已派发时先进入“停止中”，演练丢失结果后进入“结果不明”。人工核实只增加备注，不把原状态改成成功或未执行。正式版的取消事务、实例撤销、SQLite 持久化与实际目标复核仍须独立实现和真机验证。

走查任务、证据和缺口仅保存在本地 `p0/`，不纳入仓库。原型与正式应用的关系见[原型说明](../docs/prototype.md)。
