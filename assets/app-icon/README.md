# DSHX 应用图标：鲸鱼拿手机

以项目现有的 DeepSeek 鲸鱼矢量轮廓为基础，保留腹部留白，让鲸鱼原有的右侧鱼鳍托住一部略微倾斜的手机。手机绘制在鲸鱼后方，原有鱼鳍位于手机边缘前方，保持鱼鳍原本的形状，不新增手掌、手指或手臂。主方案使用暖白底与蓝色主体，并提供反白和深色配色。

这是 DSHX 社区应用的衍生图标设计，不代表 DeepSeek 官方应用。原始鲸鱼的来源及 MIT 许可见 [LICENSE.txt](LICENSE.txt)。

## 文件

| 文件 | 用途 |
| --- | --- |
| `dshx-icon-design-board.png` | 三种配色、小尺寸与圆形裁切的设计对照图 |
| `dshx-icon.svg` | 主方案：暖白底、蓝鲸，1024 × 1024 矢量源文件 |
| `dshx-icon-1024.png` / `dshx-icon-512.png` | 主方案 PNG，可用于展示或导入资源工具 |
| `dshx-icon-blue.svg` 及对应 PNG | 蓝底白鲸配色 |
| `dshx-icon-dark.svg` 及对应 PNG | 深灰底、浅蓝鲸配色 |
| `dshx-mark.svg` / `dshx-mark-1024.png` | 透明背景蓝鲸标志，用于排版与品牌展示 |
| `dshx-adaptive-foreground.svg` / 对应 PNG | Android 自适应图标前景素材，包含额外安全留白 |
| `dshx-monochrome.svg` / 对应 PNG | Android 主题图标的单色前景素材，使用透明背景与黑色实体 |

SVG 是以几何路径保存图形的矢量格式，可以无损缩放；PNG 是按像素保存的图片，用于预览和直接展示。

## 配色与形状

- 主方案背景：`#F7F7F5`；主体：`#3578F6`。
- 反白方案背景：`#3578F6`；主体：`#FFFFFF`。
- 深色方案背景：`#1D201D`；主体：`#83B1FF`。
- 手机采用圆角机身和留空屏幕，用简洁外形保证缩小后的辨识度。
- 图标本身不包含字母名称，避免缩小后出现不可读的小字。
- 有底色的交付图保持完整正方形画布。设计对照图中的圆角与圆形是裁切演示，不烘焙到交付图内。

## Android 接入说明

自适应图标是由应用提供前景与背景、由 Android 桌面决定最终圆形或圆角外形的图标机制。开发者配置两个图层，桌面负责裁切和部分动态效果；它与已经固定圆角的普通 PNG 不同。

`dshx-adaptive-foreground` 已缩小主体，确保关键图形处于画布中心直径约 61.1% 的安全圆内。搭配主方案时，背景使用纯色 `#F7F7F5`。`dshx-monochrome` 使用相同布局，其透明度定义形状，最终颜色由支持主题图标的桌面决定。透明背景的 `dshx-mark` 用于普通展示，不能代替已经预留安全空间的自适应前景。

应用已选用第一个“浅底蓝鲸”方案。应用清单中的普通图标与圆形图标均引用 `@drawable/icon`，背景为暖白 `@color/icon_background`，前景为 `@drawable/icon_foreground`。前景已从确认后的 SVG 转换为 Android 矢量资源，保留原有鱼鳍托住手机的图形与安全留白。

Android 13 及以上使用 `drawable-v33/icon.xml`，额外声明单色图层。该图层复用前景的透明形状，由系统决定主题颜色。蓝底白鲸与深色配色作为独立素材保留；默认应用图标固定采用浅底蓝鲸。
