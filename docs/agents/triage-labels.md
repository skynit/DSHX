# 任务分类标签

工程技能使用以下五种标准角色，本仓库保留同名 GitHub 标签。

| 技能角色 | 仓库标签 | 含义 |
| --- | --- | --- |
| `needs-triage` | `needs-triage` | 维护者需要评估和分类 |
| `needs-info` | `needs-info` | 等待提出者补充信息 |
| `ready-for-agent` | `ready-for-agent` | 规格充分，可交给 AI 代理实施 |
| `ready-for-human` | `ready-for-human` | 需要人工实施或处理 |
| `wontfix` | `wontfix` | 决定不处理 |

技能提及标准角色时，使用“仓库标签”列中的实际名称。

这些标签表示处理状态，可以与 `bug`、`enhancement` 等任务类型标签并用。
分类评估和状态流转按 `triage` 技能执行。

如需调整名称，修改本表中的“仓库标签”列，并同步维护 GitHub 标签。
