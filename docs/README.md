## 模块说明

| 模块 | 说明范围 |
|---|---|
| [应用生命周期与引擎管理](engine.md) | 解释应用启动时谁创建引擎、后台服务如何持有它，以及停止与故障恢复的区别。 |
| [离线运行包安装与完整性检查](runtime.md) | 运行包是随 Android 安装包提供的程序与依赖集合，由构建脚本生成、引擎安装组件校验；它与用户数据分开。 |
| [原生管理界面与官方聊天网页](interface.md) | 原生管理界面由 Kotlin 应用创建；聊天网页由官方引擎提供并放入系统网页容器。两者在同一个应用中承担不同职责。 |
| [本机通信、会话登记与工具准入](bridge.md) | 通信桥是宿主每次启动时建立的本机认证连接，用来交接请求；会话登记保存本次运行的有效身份，与持久聊天历史分开。 |
| [文件、搜索、命令、附件与终端](tools.md) | 模型工具由引擎注册并根据模型请求执行；手动终端由用户直接操作。本文说明两种入口的执行方式和文件访问边界。 |
| [手机能力、界面观察与操作小窗](phone.md) | 手机能力模块把模型提出的命名操作转交给 Android 系统；开关、系统授权、观察凭据和实际执行结果分别检查。 |
| [助手人设、调用用量与动作记录](assistant.md) | 人设是用户设置的名字、身份和回答要求；调用账本是程序追加的模型用量与动作记录，和保存完整对话的会话日志分开。 |
| [语音输入、唤醒、播报与本机小模型](voice.md) | 语音流程由宿主的语音协调对象持有，把收音、识别、正式会话和播报串起来。本机分流是按规则把少量简单文字任务交给设备上的模型。 |
| [本地长期记忆](memory.md) | 长期记忆由用户管理或由会话整理任务生成，保存偏好、事实和经验；它与完整聊天记录、用户导入的知识文档分别存储。 |
| [本机知识库、关键词与语义检索](knowledge.md) | 知识库由用户主动导入参考资料形成；程序负责文档版本、分块、索引和引用。语义加工需单独选择模型服务，不等同于本机关键词查找。 |
| [共享读取额度与知识任务控制](read-budget.md) | 共享读取额度由记忆和知识模块共同维护，限制同一次真实用户请求读取的资料量；后台业务任务另用操作编号与任务编号跟踪。 |
| [插件管理与底层 Android 兼容](plugins.md) | 插件由上游管理器安装和启用，项目提供 Android 上可执行的包管理入口和兼容层；成功安装与允许模型调用插件工具分别判断。 |
| [数据迁移、会话备份与知识归档](backup.md) | 数据迁移由宿主在引擎停止时整理旧目录；会话备份与知识归档分别导出不同业务数据，均不代表完整应用备份。 |
| [早期原型与 P0 证据工具](prototype.md) | prototype 是项目早期独立安装的交互原型；P0 是维护者组织的早期可行性验证阶段。这些文件不进入正式应用的运行链路。 |

## 当前验证边界

正式宿主已接入官方聊天、文件与命令、手机能力、助手设置、语音、本机小模型、记忆、知识和归档。当前仍是开发版本，以下事项不能仅凭代码存在或此前其他包的结果判定通过：

- 知识功能的真实模型自主问答、真实嵌入与集合摘要效果。
- 目标 ARM 手机上的知识功能、容量与性能，以及记忆自动整理的语义质量。
- 覆盖安装后的真实数据迁移、断电持久化、更多系统与机型兼容。
- 在线播报的网络可达性、火山账户与音色权限，以及各手机系统识别的质量、服务可用性、资源占用与发行核对。

历史计划和逐轮证据保存在本地 `plan/`，不作为公开说明的链接依赖；构建与设备检查产生的文件仍放在被忽略的产物目录。新增实现说明写入本目录，实施计划和过程记录继续留在 `plan/`。
