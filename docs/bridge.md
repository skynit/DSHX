# 本机通信、会话登记与工具准入

[说明索引](README.md) · [术语与架构](architecture.md) · [返回项目](../README.md)

通信桥是宿主每次启动时建立的本机认证连接，用来交接请求；会话登记保存本次运行的有效身份，与持久聊天历史分开。

本文所称 **Android 宿主**是 `app/` 中由系统创建的 Kotlin 应用，负责页面与系统交接；**dsh** 是宿主启动的官方智能体引擎，负责会话、模型请求和工具调度；**Node** 是执行 dsh 与适配模块的 JavaScript 运行程序。其他通用概念见[术语表](architecture.md#术语与整体架构)。

**会话**由 dsh 创建并分配稳定编号，保存一段对话与工具事件；**工具**由引擎或插件注册，是模型可以提出调用的命名操作，执行结果由程序返回。

**工作区**是宿主准备的默认任务目录，也用于筛选项目资料与记忆；它与整个应用私有数据目录分开，不自动构成文件隔离。

**Full（完全权限）**是宿主为有效登记会话返回的工具准入模式，使用应用已有系统权限；它不授予 root，也不替代各项系统授权。

## 职责与实现

| 文件或组件 | 作用 |
|---|---|
| [`ToolPolicy.kt`](../app/src/main/java/local/dshx/app/ToolPolicy.kt) | `Engine` 创建的本次运行会话登记表，保存编号、父子关系、根会话及统一 Full 状态；不持久保存聊天内容 |
| [`PolicyBridge.kt`](../app/src/main/java/local/dshx/app/PolicyBridge.kt) | `Engine` 每次启动创建的本机 TCP 服务端，校验实例和随机认证值，处理会话登记、查询、手机调用、本机推理和原生管理请求 |
| [`host.mjs`](../core/host.mjs) 中的 `PolicyHost` | Node 侧连接客户端，维护会话状态缓存、请求编号、超时和取消；同时接收 Android 发来的语音、记忆、知识和后台托管管理请求 |
| [`guard.mjs`](../core/guard.mjs) | 作为固定 Android 插件加载，监听 dsh 智能体创建、请求、空闲和销毁，登记会话、收尾手机动作，并安装工具准入检查及运行事实提示 |
| [`policy.mjs`](../core/policy.mjs) | 定义工具可见性、最终调用检查、文件路径处理和单次异步调用上下文；不是系统权限申请器 |

**连接如何工作。** 宿主启动本机随机端口，将端口、实例和认证值仅传给本次 Node 子进程。客户端首先发送 `version`、`instance`、`token` 握手；服务端成功后只接纳一条有效主连接。后续 JSON 消息以换行分隔，并检查字段、长度、请求编号和状态修订号。

这是一条双向连接：Node 向 Android 查询会话并请求手机或本机推理；Android 向 Node 请求语音对话、记忆管理、知识管理和后台托管管理。手机操作及本机生成放到独立线程，避免长操作堵住状态查询和取消。连接失效时双方清空有效状态、拒绝后续调用，宿主请求停止引擎；不会凭旧缓存恢复权限。

引擎可用 `small-model` 查询当前模型分工开关与截图模型配置。此请求仍需有效登记会话，配置由宿主创建的 `SmallModel` 对象读取，只含服务与模型标识，不返回密钥；连接请求不能修改这些设置。截图工具每次读取配置，因此不依赖语音会话是否已经启动。

后台托管使用独立的 `hosting` 管理通道，只接受读取状态和保存配置；保存时携带读取到的配置版本，旧页面不能覆盖新值。它不提供模型执行接口。定时检查通过 `phone-status` 只读查询手机就绪状态，不要求先创建会话，也不接受手机动作参数；真正手机操作仍走有效会话的 `phone` 请求。详见[后台托管](hosting.md)。

**会话如何准入。** `guard.mjs` 从 dsh 自己的智能体关系取得父子归属，先登记父会话再登记子会话。宿主最多保存 64 个活跃会话、256 个本次运行归属记录。合法登记统一 Full；结束父会话时撤销其活跃后代，重启清空运行登记。磁盘上的聊天历史继续保留。

**工具如何限制。** 工具目录只向模型展示当前适配且可用的操作；真正执行入口再次检查名称、参数和实时会话。`policy.mjs` 使用 Node 的 `AsyncLocalStorage`，即为各条异步调用分别保存上下文的机制，防止并发工具把“当前会话”“文件模式”混用。源码中的旧只读、工作区写入分支用于兼容与回归，不代表原生页面存在逐会话权限切换。
