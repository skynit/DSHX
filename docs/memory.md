# 本地长期记忆

[说明索引](README.md) · [术语与架构](architecture.md) · [返回项目](../README.md)

长期记忆由用户管理或由会话、实验体整理任务生成，保存偏好、事实和经验；它与完整聊天记录、用户导入的知识文档分别存储。

本文所称 **Android 宿主**是 `app/` 中由系统创建的 Kotlin 应用，负责页面与系统交接；**dsh** 是宿主启动的官方智能体引擎，负责会话、模型请求和工具调度；**Node** 是执行 dsh 与适配模块的 JavaScript 运行程序。其他通用概念见[术语表](architecture.md#术语与整体架构)。

**会话**由 dsh 创建并分配稳定编号，保存一段对话与工具事件；**工具**由引擎或插件注册，是模型可以提出调用的命名操作，执行结果由程序返回。

**工作区**是宿主准备的默认任务目录，也用于筛选项目资料与记忆；它与整个应用私有数据目录分开，不自动构成文件隔离。

**token** 是模型计算文本用量的单位，由实际模型或服务报告；它与字符数、UTF-8 字节数不同，读取额度中的字节预算也不是实际计费用量。

## 使用入口

1. 启动 dsh，在“知识库 → 记忆 → 记忆设置”读取真实状态；默认关闭长期记忆与自动整理。
2. 在“记忆”标签中手动新增或编辑偏好、事实、经验，并选择用户通用或指定工作区范围。待确认候选只有确认后才参与对话。
3. 开启“长期记忆”允许普通对话与实验体读取相关记忆；“自动整理”独立控制保存，无需先开启读取。开启自动整理后，普通聊天按既有阈值整理，实验体在每轮完整结束后安排整理。云端模型会接收参与整理的对话或培养结果片段。
4. 关闭对话使用后仍可管理已有内容。引擎停止时只能读取本机设置摘要；会话备份不包含这份独立记忆。

## 职责与实现

长期记忆保存三类信息：偏好、事实、可复用经验。用户通用范围对有效根会话可见，工作区范围仅对匹配工作区可见；“根会话”是由用户直接使用、没有父会话或委派来源的会话，用于区别引擎创建的子任务会话。功能与自动整理默认关闭。

| 文件或组件 | 作用 |
|---|---|
| [`MemoryStore.kt`](../app/src/main/java/local/dshx/app/MemoryStore.kt) | 原生只读设置摘要和管理回执的数据解析器；引擎未启动时可读取本机设置，不直接写正式记忆 |
| [`memory.mjs`](../core/memory.mjs) | dsh 侧接入与调度，提供管理操作、自动召回、`memory_search` 和 `memory_read`，监听会话事件并管理整理任务 |
| [`memory-store.mjs`](../core/memory-store.mjs) | 声明和校验业务数据，通过 dsh 领域存储串行发布快照；负责手动保存、删除记录、范围匹配和关键词查找 |
| [`memory-extract.mjs`](../core/memory-extract.mjs) | 从已保存会话中选择完整真实文本，按来源路由请求结构化候选，并核对候选是否有用户原文依据 |

**数据结构。** 每条记忆包含稳定编号、类型、主题键 `key`、短摘要、正文、范围、来源、状态、锁定标记、更新时间及可选过期时间。主题键用于识别同范围同主题，摘要用于小量召回，正文用于追读；来源保存会话编号和事件序号。自动任务只登记待处理范围，不复制整份聊天。`active` 是已生效条目，`pending` 是待用户确认候选，锁定表示自动整理不能直接覆盖。

**自动召回。** 每次真实用户输入或具有机会编号的实验体输入获引擎接纳后，模块按真实工作区和当前文字查找有效记忆，只加入有限摘要。当前该段背景按 256 UTF-8 字节预算控制，并从已接纳会话事件重建去重记录。记忆删除、过期或更改后，后续召回会说明旧背景失效；已经进入历史的文字无法追溯从模型端撤回。需要更多内容时，模型再用两项只读工具搜索摘要和读取完整条目。

**自动整理。** 开启后，模块跟踪已登记根会话的新范围，等待 dsh 确认会话日志写入，再持久登记任务。同会话、工作区、来源模型一致的等待范围可以合并。普通触发为 4 个有效用户回合或新增用户正文 4096 UTF-8 字节，并在距离上次成功整理不足 120 秒时继续合并等待。明确记住、更正、容量保护、管理端继续和压缩开始事件可以提前处理。

整理并发为 1，调用来源轮次实际使用的服务商和模型，不任意换成另一个默认模型。每批按顺序选择完整用户文本；助手文字与旧记忆只作背景，工具输出、图片音频、推理、系统提示、压缩摘要及模块注入不作用户事实来源。输入按实际模型容量收紧，保守上限为 8192 UTF-8 字节，相关旧记忆最多 8 条、1536 字节；默认 30 秒超时，输出最多 2048 token，每批最多 10 个候选。

**实验体经验。** 实验体由 `hosting.mjs` 通过带有 `plugin:dshx-hosting` 来源及机会编号的正式会话输入触发；培养指令不是用户事实。记忆模块只选择以 `completed` 正常结束的培养轮次的最后一条有效可见回答，去掉推理块，不读取工具调用块或中断回答。候选仍需逐条匹配回答原文，仅可保存为当前工作区的“经验”，由程序添加“实验体记录：”和 `source.origin=specimen` 标记、`specimen.` 主题键前缀，不能推断用户偏好或身份。记录表示实验体自述，不能等同于独立核实的事实；空结果不强行生成记忆，重复内容合并出处，达到出处上限后省略冗余引用，不阻塞后续整理；同主题有效更正保留本轮来源及有限历史出处，锁定或冲突仍需确认。

运行时背景、工作目录、工具清单和记忆召回消息不会清除本轮培养归属。轮中会话压缩只能整理已完整结束的范围，尚未结束的培养输入必须保留到结束；重启只恢复已登记范围，新增有效交互或手动继续后再处理。关闭自动整理使旧任务失效；仅切换对话读取保留待整理范围及执行中的整理。

记忆整理与实验体的“操作方法整理”共用 `background.mjs`（后台请求协调模块，由两种整理模块调用），总并发最多为 1，人类输入优先。让位后不提交迟到结果；记忆保留原有来源模型、阈值、范围与独立开关，待新有效输入或手动继续再处理。候选操作方法使用真实工具回执，而这里的“实验体经验”仍只根据可见回答保存，不能混为同一证据等级，详见[实验体](hosting.md)。

**提交与冲突。** 普通候选正文和摘要必须有真实用户原文依据，凭据、密码和验证码排除。程序在提交前再次检查状态代次、开关、来源、删除记录、锁定状态及条目版本；明确记住请求、锁定项更新或冲突可能生成待确认候选，不能只因模型说“已记住”就视为保存成功。成功批次把条目、剩余任务与进度一起发布；单条用户消息超容量时保留失败任务，不越过它。失败最多再明确重试一次。

**重启与容量。** 重启只恢复本代次已登记范围，不扫描全部历史，不立即发模型请求；用户继续整理或产生新交互后才启动。关闭保留正式数据并使旧任务失效。上限为 500 条记忆、32 个任务、256 个跟踪会话、2000 条忽略记录、完整快照 4 MiB；格式损坏或未知版本拒绝写入，保留原文件。
