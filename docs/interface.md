# 原生管理界面与官方聊天网页

[说明索引](README.md) · [术语与架构](architecture.md) · [返回项目](../README.md)

原生管理界面由 Kotlin 应用创建；聊天网页由官方引擎提供并放入系统网页容器。两者在同一个应用中承担不同职责。

本文所称 **Android 宿主**是 `app/` 中由系统创建的 Kotlin 应用，负责页面与系统交接；**dsh** 是宿主启动的官方智能体引擎，负责会话、模型请求和工具调度；**Node** 是执行 dsh 与适配模块的 JavaScript 运行程序。其他通用概念见[术语表](architecture.md#术语与整体架构)。

**会话**由 dsh 创建并分配稳定编号，保存一段对话与工具事件；**工具**由引擎或插件注册，是模型可以提出调用的命名操作，执行结果由程序返回。

## 职责与实现

每次新打开应用时，主页面立即通过现有后台服务启动 dsh；后台服务是 Android 创建并显示常驻运行通知的对象，负责管理引擎进程，不依赖启动动画播放结束。已在运行或准备中的引擎会被复用；页面重建不重新启动用户已手动停止的引擎。如果 Android 回收了整个应用进程，恢复页面时会重新启动尚未初始化的引擎。

[`StartupScreen.kt`](../app/src/main/java/local/dshx/app/StartupScreen.kt) 是主界面调用的启动画面，只观察真实引擎状态。它复用明暗主题和鲸鱼托手机标志，以 320 毫秒淡入、轻微上移和缩放呈现；细线游标表达等待，不代表完成百分比。淡入后等待引擎就绪、失败或最多 1600 毫秒，再以 160 毫秒淡出进入工作台；尚未完成的启动继续在后台进行。系统关闭动画时直接呈现静态标志、细线和状态，不添加固定的品牌停留时间。

应用回到前台时检查本应用的无障碍授权。**无障碍授权**是用户在 Android 设置中为「DSHX 手机操作」开启的系统开关，允许服务读取界面并执行点击、滑动；**服务已连接**则表示 Android 已创建并连接该服务，两者不是同一状态。启动检查读取系统授权，避免把连接中的服务误判为尚未授权。未开启时，启动画面结束后显示应用内提示，「去开启」进入系统无障碍设置，「稍后」或关闭可继续使用应用；同一次打开过程中处理过提示后不再重复弹出。授权不会由应用自动开启，运行状态通知仍由原有后台服务负责。

| [`SettingsScreen.kt`](../app/src/main/java/local/dshx/app/SettingsScreen.kt) | 原生页面调用的设置组件，组织设置总览与助手、语音、任务分工、手机权限、备份等详情表单；详情页返回设置总览，再返回工作台 |
| [`chat.css`](../app/src/main/assets/chat.css) | 主页面在可信聊天页加载后注入的网页样式，统一网页语义色、边框、圆角和焦点外观；不负责工具准入或模型路由 |
| `res/` 中的图标、字符串和 XML | 由 Android 构建打包；提供应用标识、无障碍描述和文件分享路径等系统资源 |

管理页面使用 **Miuix 0.8.8**（Kotlin 控件库）和 Lucide 图标，由 Gradle 声明依赖；视觉沿用 Qoder 的暖中性色与克制边框。聊天网页仍使用固定版本 dsh 自带的 React 页面，React 是上游组织网页组件的框架；项目没有另写一套独立聊天状态。

深色主题以中性黑 `#0E0E0E` 为主背景，卡片、输入框、选中态分别使用 `#181818`、`#202020`、`#292929`，边框使用 `#333333`。原生共享色板与聊天网页样式保持同一层级，文字和次级文字使用中性灰，蓝色交互强调及成功、警告、失败的状态色独立保留。

原生动效集中配置在 [`AppMotion.kt`](../app/src/main/java/local/dshx/app/AppMotion.kt)。**动画参数**是开发者为界面变化配置的时间、变化曲线和回弹程度，与业务状态和请求超时分别管理。选中颜色使用 160 毫秒短反馈；边缘返回的收尾、设置项展开、播报配置区域的高度变化以及文件列表位置变化使用无回弹弹簧，能够从变化中的当前位置继续调整。高频输入和语音消息正文不逐字播放动画，新消息仅短暂淡入，“回到最新”使用平滑滚动。

**页面拖动预览**由 [`PageTransition.kt`](../app/src/main/java/local/dshx/app/PageTransition.kt) 创建：它只保存本次拖动的目标、方向、进度、速度及收尾任务，不保存正式导航结果。工作台、对话、语音和设置共用这一实现；对话、语音及设置返回工作台，工作台没有上一级，因此完成手势只展开底栏。底栏默认隐藏，随返回进度从底部滑出，完成后保留供选择，点击目标入口后再次收起；工作台的“页面导航”以及各页点击返回入口提供无需拖动的操作方式。正文与底栏共享测量空间，底栏出现时不会盖住末尾内容或语音操作。

正文区域按“工作台、对话、语音、设置”顺序左右拖动切换，左滑进入下一页、右滑进入上一页，首尾不循环。正文翻页位移使用 1.65 倍拖动映射，松手预计进度达到 16% 即完成，快速甩动阈值为每秒 0.5 个页面宽度；与边缘返回的 35% 进度门槛分开配置。普通翻页期间底栏保持隐藏，完成后才切换正式页面；滑动进入语音页不自动开始录音，切换到文字对话仍停止当前语音任务。

应用在左右边缘带识别向内拖动，默认宽度为 32dp；系统占用边缘时，应用只保留系统区域内侧半个边缘带的补充区域。手势区域宽度从 Android 创建的根窗口（主界面最外层的系统窗口，仍保留完整系统边距）读取，避免内层界面收到已经被消耗的边距。先超过系统提供的移动识别距离，再要求横向位移大于纵向位移的 1.3 倍；正文中部的横向操作用于相邻主页面切换，纵向滚动以及多指操作不成为页面转场。**手势归属**是本次拖动交给应用返回还是系统返回的选择；识别后保持归属及起始边缘稳定，反向移动只减少当前预览进度。支持预测返回的系统将真实进度交给应用，系统决定该次返回完成或取消；三键导航与系统返回键没有拖动进度，直接进入同一收尾路径。

应用自行识别的拖动把位移和速度除以页面宽度，使用与屏幕尺寸无关的比例：每秒向内超过 0.8 个页面宽度且已有至少 2% 进度时，可以短距离甩动完成；每秒向外达到 0.8 个页面宽度则取消，即使已拖过一半。其余情况把松手速度按 0.18 秒折算为预计进度，达到 35% 才完成；慢拖不足条件则回弹。松手后从正在显示的位置及当前速度进入共享弹簧，在边界限制向外的初速度，避免撞到错误边界后突然结束。收尾期间再次从边缘向内拖动，会取消旧收尾并从当前可见位置重新接管。

**真实返回提交**由 `DshScreen` 在完成收尾后执行，与预览分开；一次有效完成只提交一次，过期收尾任务不能再次改变页面。预览中的目标页不能点击或被屏幕阅读器当作活动页访问。取消、系统取消、指针丢失、多指打断、页面变化和组件卸载都会取消旧任务并归零；首次预览但未正式进入的目标页不保留临时页面状态。拖动预览不调用语音启停。原生横向滚动控件优先处理自身拖动；聊天网页通过触摸起点报告其父级是否还有可横向滚动的区域，输入框及可编辑区域优先编辑，只有正文没有横向滚动任务时才允许翻页。聊天页仅在正式成为活动页后通知语音对象选择会话，取消网页预览不改变当前语音会话。

文字、工具栏图标及语音操作按钮复用 Miuix 的按压反馈，文字按钮本体和图标按钮的点击区域至少为 48dp。**dp** 是 Android 随屏幕密度换算的布局单位，由系统完成像素换算；文字仍使用随系统字号调整的 sp 单位。按钮图标与文字使用相同的主题语义色，主操作、普通操作与危险操作保持可辨认的层级；启用、禁用和焦点颜色使用统一短过渡，禁用操作立即生效，不等待动画结束。图标按钮保留操作名称供屏幕阅读器识别，字体放大时文字按钮可随内容增高。

**页面状态保存器**由 Compose 创建，按页面名称保留可保存的编辑内容与滚动位置；它不保存模型回答或取代磁盘存储。拖动预览只短暂保留当前页及目标页，各自使用自己的页面名称和状态，避免旧页面提前显示新页面内容。知识库另按资料、记忆、文件、技能的标签名称保存状态，退出中的标签不作为活动页显示弹窗或持续轮询。聊天仍复用 `MainActivity` 持有的同一个 WebView，不为过渡创建另一份网页会话。

系统关闭动画时，松手收尾和其他自动播放的原生过渡直接到达最终状态；手指拖动期间仍显示直接跟随输入的预览。选中样式、字段内容和操作入口仍完整可见。模拟器界面检查只能验证切换、状态恢复和最终布局；正式顺滑度和掉帧需在启用优化的 Release 包上使用实体设备验证，不能由截图或开发包构建通过推断。

底部横栏展开后提供“工作台、对话、语音、设置”四个入口。“对话”使用消息图标，承载官方聊天、模型配置、会话及网页入口；“语音”使用电话图标，系统识别服务和工作区已就绪时，点击即开始语音聊天。语音页占满底栏上方的整个页面，不使用半屏卡片；顶部提供文字对话和语音设置入口，多轮识别文字和助手回答从上往下放在可滚动的主体区域，当前状态与开始、结束操作固定在底部。切换到文字对话会停止当前语音任务。系统识别服务不可用或工作区未启动时，显示设置或启动入口，不把不可用动作做成没有反馈的按钮。聊天网页下方不再附加语音按钮面板。

工作台显示实际启停状态和按需诊断；设置页管理手机宿主增加的功能。语音页按轮次显示“你 · 语音转文字”和“助手”：自己的话使用右侧浅色气泡，助手正文保持宽松行距，两者均可选择复制。识别完成立即追加用户消息，等待回答时显示占位，回答生成时逐段补入对应消息；播报时只标记最新回答，下一轮不会覆盖上一轮。停止、失败和页面切换保留已显示内容；用户向上阅读旧消息时暂停跟随，“回到最新”或手动滚到底后恢复跟随。列表末尾保留定位锚点，长回答也能滚到真正的底部。这些消息由应用持有的语音对象在内存中保存，完整历史仍保存在同一段 dsh 会话中；切换会话会清空当前语音页的显示，重新选择原会话不会从 DSH 历史恢复语音列表，应用进程退出后也不会保留此内存列表。先通过语音创建会话，再首次打开文字页时，也会定位到该会话。网页组件要求 Chromium 126 或更新版本；语音聊天不依赖网页是否加载成功。服务是否运行、网页是否加载成功、模型是否请求成功分别判断，不能互相代替。

底部状态面板区分准备、等待唤醒、收音、识别、回答、播报和停止阶段，阶段由语音协调对象在真实操作边界更新，界面不依赖状态文案猜测录音状态。**音量条**是原生收音对象发布的真实强弱反馈：系统识别时使用识别服务提供的音量回调，本机唤醒时根据麦克风样本能量每约 100 毫秒计算；它不代表部分识别结果，也不是装饰动画；它使用独立状态流（只传递最新音量的数据通道），由绘制区域读取，不使整段消息列表跟随音频更新。静音时平稳，识别、停止或失败时归零；系统关闭动画时保留静态麦克风标识和状态文字。音量区域预留固定高度，阶段切换不挤动底部操作。新消息与状态色沿用 `AppMotion` 的短反馈，正文不逐字播放。

“知识库”统一管理资料、记忆、文件和技能，从工作台与设置都可进入同一个独立页面。顶部四个标签固定显示，主体独立滚动；切换标签保留搜索筛选；资料编辑草稿由原有知识存储对象保留，回到资料页可继续编辑。

| 标签 | 管理内容与主要操作 |
|---|---|
| 资料 | 用户导入并供引擎检索的文档；支持搜索、添加和查看原文。集合、处理任务、检索设置与知识归档集中在“资料管理”中 |
| 记忆 | 用户手动保存或模型整理出的长期偏好、事实和经验；直接查看、新增、编辑与确认候选，启用与自动整理位于“记忆设置” |
| 文件 | 用户上传的原件及官方引擎保存的聊天附件；支持筛选、文本预览和系统导出。Markdown/TXT 可加入资料集合；聊天附件保留原件，避免破坏历史会话引用 |
| 技能 | Skill，即可重复使用的操作指令文件，由用户创建或配置、由引擎的技能读取器加载；与提供事实依据的资料不同，技能描述如何完成任务。支持新建、编辑和删除用户及默认工作区技能 |

[`LibraryScreen.kt`](../app/src/main/java/local/dshx/app/LibraryScreen.kt) 由原生页面创建，组织四个标签并复用现有资料、记忆管理组件及主题；[`LibraryStore.kt`](../app/src/main/java/local/dshx/app/LibraryStore.kt) 读写独立上传原件和引擎现有用户技能目录。资料正式状态和长期记忆仍由 Node 管理，文件加入资料通过既有文件暂存及导入流程提交。上传原件、聊天附件、资料归档和会话备份各有保存范围，不因统一入口变成同一份数据。编辑技能保留原有元数据和同目录资源，保存、删除前校验原文摘要，发现外部修改时要求重新打开。

设置总览按助手、能力、应用分组，提供“助手与资料”“语音交互”“任务分工”“手机操作与权限”“实验体”“微应用”“外观”“备份与恢复”。“助手与资料”管理名字、身份与提示词，并提供知识库入口；“外观”支持跟随系统、浅色和深色。微应用支持描述需求创建应用、打开页面、配置设置、独立启停及查看记录，详见[微应用](apps.md)。

“设置 → 实验体”打开原生培养主画面：彩铅实验体居中呈现，内部形态按已确认的纤细比例绘制，上下连接细丝分别延伸至页面边缘；屏幕本身表达培养容器，不再绘制实体罐壁、顶盖和底座。插画是静态视觉，不表示模型训练、成长分数或执行进度。深色主题使用适配深色纸面的彩铅素材，不对整页反色。

“培养设置 → 背景图”支持通过系统图片选择器更换主画面背景，或恢复默认彩铅插画。更换后自动生效，无需启动工作区或保存培养指令。自定义图片居中裁切铺满主画面，标题和底部状态保留主题底色以便阅读；浅色和深色主题共用这张自定义图片，恢复默认后重新使用各主题对应的插画。应用将图片副本保存到私有目录，重启后保留，原文件移动或删除不影响显示；图片大小限制为 20 MB，导入时按比例缩小至最长边不超过 2048 像素，并按照片方向显示。取消选择不更改背景，读取或保存失败保留原图并提示错误。

右上角“打开培养设置”进入独立的“培养设置”页面；系统返回、边缘返回和页面返回按钮先回到实验体，再回设置总览。培养设置保留原有启停、概率、任务说明、目标会话、状态、刷新及最近记录；任务说明在界面中命名为“培养指令”。正文独立滚动，保存操作固定在正文下方并实际占用布局空间，避免遮挡末尾内容。主画面仅在前台可见时约每 10 秒读取一次实际状态，进入培养设置及应用回到前台时也会读取；这些查询不触发模型。草稿由主画面与设置共用，刷新真实状态不覆盖正在编辑的草稿；保存成功才返回主画面，失败时留在设置页显示错误；用户主动离开设置后，较迟返回的旧保存回执只更新状态，不改变后来进入的页面。开关仍立即提交启停；关闭使用已保存配置，即使草稿未通过校验也能请求停止。详见[实验体与概率触发](hosting.md)。

“设置 → 语音交互”显示系统识别可用性并提供系统语音设置入口，不再提供本地识别模型下载；从系统设置返回后刷新可用状态。关键词唤醒后需等待进入收音状态再说问题。

“设置 → 任务分工”独立于“语音交互”，统一管理文字或语音中的简单任务与截图识别。简单任务可选择默认本地、导入本地或在线模型，截图可单独指定支持图片的服务与模型。保存后下一次对应任务读取新配置；当前 GGUF 导入引擎只支持文字，截图能力以实际模型声明为准。

附件选择绑定当前 WebView 和启动实例：系统文件选择器返回后，只把可读且仍属于当前页面的文件引用交还聊天页；旧实例、取消或不可读文件不生成附件。网页选择会话还会通知原生语音模块，使语音接入当前会话。网页只提供必要的宿主交接，不因此获得任意原生方法调用能力。
