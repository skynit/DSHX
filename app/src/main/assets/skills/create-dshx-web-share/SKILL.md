# 创建共享网页

共享条目是手机保存的网页名称和服务地址。网页内容由服务提供；DSHX 负责让浏览器经端点访问，不负责启动或保活服务。只在用户当前的本机主会话操作，不能替远程聊天访客登记或公开服务。

## 先确认要分享什么

- **已有服务**：使用用户指定的固定 HTTP/HTTPS 地址；手机本机写 `127.0.0.1`，局域网服务写手机当前 Wi-Fi 或有线网络内的 IPv4 地址。不扫描其他机器，不填写 DSHX 引擎或管理地址。用手机发起一次不修改数据的请求核实地址、状态和内容；HTTPS 不跳过证书检查。
- **新做网页**：把网页放在工作区的独立项目目录。简单页面可用 HTML/CSS/JS 和 Node 的 `node:http`，先用 `command -v node` 确认运行环境。生成 `server.mjs` 和所需资源，服务只映射明确要分享的路由和文件；不暴露整个工作区、目录列表、密钥或调试接口。只监听 `127.0.0.1`，可用端口 `0` 让系统分配空闲端口，并在监听成功时打印实际地址。页面资源使用相对或同网站路径，不另注册 Service Worker（共享入口已用后台脚本接管请求）。
- 用 `terminal_open` 打开持久终端，按工具实际参数启动服务，通过 `terminal_read` 取得真实地址。另发一次请求验证页面和关键资源已可读；不能只看终端没有报错。保留终端编号和可复用启动命令；用 `terminal_signal` 或 `terminal_close` 停止本次服务。引擎退出或系统回收进程后，服务可能需要手动重启；若要沿用原共享地址，重启时指定原端口。

## 登记并交付

1. 调用 `web_share_create`，传入 `name`、`address` 和本次创建的标准小写 UUID `operationId`（可由 `node -p 'crypto.randomUUID()'` 生成）。结果不确定时用原编号和原参数重试，不换编号重复创建。未提供该工具时，交付已验证的地址，提示在「设置 → 网页共享」手动登记；不要写入应用私有配置。
2. 按真实回执说明条目状态。新条目默认停用；不自动启用条目、公开端点、退出隐身、批准局域网或提供尚不可访问的公开链接。需要公开时，由用户打开「设置 → 网页共享」，检查地址并启用；端点同时需要在线且公开。公开后的条目不只是给收到链接的人，也可被公共端点访客发现。
3. 分别说明本机页面验证和外网验证。交付项目路径、实际服务地址、标题、启动及停止方式；未在浏览器从端点打开过，不宣称外网已经能访问。
